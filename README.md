# Cloud Hopper

Jednoduchá Flappy Bird-like webová hra postavená bez backendu a bez externích herních assetů.

## Spuštění

Otevři `index.html` v prohlížeči, případně projekt publikuj jako statický web (např. GitHub Pages).

## Ovládání

- kliknutí / tapnutí / mezerník = skok
- po prohře kliknutí / tapnutí / mezerník = nová hra

High score se ukládá lokálně v prohlížeči.
